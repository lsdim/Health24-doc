# Health24 IRP Helper (Chrome Extension)

Цей проект допомагає лікарям у МІС Health24 автоматично розподіляти результати діагностичних звітів у таблиці ІРП (Індивідуального реабілітаційного плану).

## Основні можливості
- **Розумний розподіл:** ШІ Gemini автоматично групує дані по інструментах (СОРМ, WOMAC, ММТ, гоніометрія тощо).
- **Визначення періодів:** Аналіз дат для розділення на початкове та заключне обстеження.
- **Вбудована кнопка:** Додається прямо в інтерфейс Health24 над потрібною таблицею.
- **Виправлення описок:** ШІ автоматично уніфікує назви інструментів, навіть якщо вони написані з різною кількістю пробілів чи символів.

## Встановлення
1. Скопіюйте папку `extension/` на свій комп'ютер.
2. Відкрийте Chrome і перейдіть на сторінку `chrome://extensions/`.
3. Увімкніть **Developer mode** (Режим розробника).
4. Натисніть **Load unpacked** (Завантажити розпаковане розширення) і виберіть папку `extension/`.
5. Отримайте API ключ для Gemini на [Google AI Studio](https://aistudio.google.com/app/apikey) та вставте його в налаштування розширення.
